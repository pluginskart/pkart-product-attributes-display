Displays selected WooCommerce product attributes inside product blocks.

== Description ==

ShopAttributes allows you to display WooCommerce product attributes inside WooCommerce product blocks.

The block can display selected product attributes such as size, color, material, thickness, width, length, and other custom WooCommerce attributes.

== Features ==

* Display WooCommerce product attributes.
* Automatically detect WooCommerce attributes.
* Display taxonomy and custom product attributes.
* Use the block inside WooCommerce product blocks.
* Supports attribute prefixes and suffixes.
* Lightweight and simple.

== Requirements ==

* WordPress 6.5 or later.
* WooCommerce.
* PHP 7.4 or later.

== Installation ==

1. Upload the `shop-attributes` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the `Plugins` screen in WordPress.
3. Make sure WooCommerce is installed and activated.
4. Add the ShopAttributes block inside a WooCommerce product block.
5. Select the product attribute you want to display.

== Frequently Asked Questions ==

= Does this plugin require WooCommerce? =

Yes. WooCommerce must be installed and activated.

= Where can I use the block? =

The block is designed to be used inside WooCommerce product blocks where the product context is available.
